# STM32 正式小闭环 2：电机速度斜坡

本闭环目标：

- 增加正式 `bsp_motor` 底层输出模块。
- 增加正式 `car_control` 电机高层控制模块。
- 支持前进、后退、左转、右转、原地左转、原地右转。
- 所有运动命令都经过速度斜坡，不能从 0 直接跳到目标速度。
- STOP、通信超时仍然立即停车。

## 1. 安全限制

- STM32 本地最大速度：`60%`。
- 单条运动命令最大持续时间：`3000 ms`。
- 默认 ramp 时间：`500 ms`。
- STOP 不走 ramp，立即清 PWM、方向脚和 STBY。

## 2. 编译前确认

Keil/MDK 的 C/C++ Define 应为：

```text
USE_HAL_DRIVER,STM32F103xB
```

不要默认启用：

```text
ENABLE_STM32_TEST_MODE
```

## 3. 运动命令格式

```text
AA 55 04 CMD SPEED DURATION_L DURATION_H CHECKSUM
```

- `SPEED`：0 到 100，STM32 内部限制到最大 60。
- `DURATION`：小端，单位 ms。0 表示持续运动，直到 STOP 或超时。

## 5. 推荐测试顺序

1. 上电，不发送任何运动命令，确认电机不转。
2. 发送 `REQUEST_STATUS`，确认 motor state 为 0，速度为 0。
3. 发送低速前进 20%，800 ms。
4. 观察 motor status：target speed 为 20，current speed 从 0 逐步上升。
5. 等 800 ms 后，current speed 逐步下降到 0。
6. 发送 STOP，确认立即变为 0。
7. 测试后退、左转、右转。
8. 发送高速度如 90%，确认 STM32 上报 target speed 被限制到 60。
9. 停止发送心跳或命令超过 3 秒，确认通信超时停车。

## 6. 正常现象

- 电机启动不是瞬间满速，而是约 500 ms 逐步到目标速度。
- 运动命令持续时间到期后，约 500 ms 平滑降速到 0。
- STOP 立即停车。
- 超过最大速度的命令会被限制到 60%。
- 超过最大 duration 的命令会被限制到 3000 ms。

## 7. 失败先检查

- `bsp_motor.c` 和 `car_control.c` 是否加入 MDK 工程。
- TIM3_CH1/CH2 是否已经初始化并启动 PWM。
- TB6612 STBY 是否接 PB10。
- PA6/PA7 是否接左右电机 PWM。
- PB12/PB13/PB14/PB15 是否接方向脚。
- 电机电源是否独立供电且与 STM32 共地。
- 左右电机方向是否接反；如果接反，先记录现象，不要直接改 CubeMX。
