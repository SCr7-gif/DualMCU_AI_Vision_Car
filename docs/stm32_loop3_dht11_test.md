# STM32 小闭环 3：DHT11 温湿度读取测试

## 1. 目标

在不阻塞主循环的前提下，让 STM32 通过 PB5 读取 DHT11 温湿度，并通过 `CMD_STATUS_SENSOR = 0x81` 上报给 ESP32-P4。

本闭环只做 DHT11，不做超声波。超声波距离字段暂时固定为 `0`。

## 2. 实现策略

- PB5 使用 CubeMX 已生成的 `DHT11_Pin` 和 `DHT11_GPIO_Port`。
- 读取开始时 PB5 配置为输出并拉低。
- 主循环继续运行，18 ms 后再切换到输入上拉并读取 40 bit 数据。
- 每个等待 DHT11 电平变化的步骤都有微秒级 timeout。
- 读取间隔至少 2000 ms。
- 不使用 `HAL_Delay()`，不在主循环里做永久等待。

## 3. 传感器状态帧

STM32 上报：

```text
AA 55 06 81 dist_l dist_h temp hum dht_ok checksum
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `dist_l/dist_h` | 距离，单位 cm x10，小端；本闭环暂时为 0 |
| `temp` | DHT11 温度整数值 |
| `hum` | DHT11 湿度整数值 |
| `dht_ok` | `1` 表示最近一次读取成功，`0` 表示失败或尚未读到 |

## 4. 手动请求状态

ESP32 或串口助手发送：

```text
AA 55 01 40 41
```

期望 STM32 回复：

- `0x80` 基础状态
- `0x84` 电机状态
- `0x81` 传感器状态

## 5. 测试步骤

1. 确认 DHT11 DATA 接 PB5，VCC/GND 正确，DATA 有上拉。
2. 烧录 STM32。
3. 上电后等待至少 2 秒。
4. 串口发送 `AA 55 01 40 41`。
5. 查看 `0x81` 帧中的 `temp/hum/dht_ok`。
6. 拔掉 DHT11 DATA 或断开传感器，再等待 2 秒并请求状态。

## 6. 正常现象

- 传感器连接正确时，`dht_ok = 1`，`temp/hum` 为整数温湿度。
- 传感器断开或接线错误时，`dht_ok = 0`。
- 传感器失败时主循环仍能响应心跳、急停和电机状态请求。

## 7. 失败先检查

- PB5 是否接到 DHT11 DATA。
- DHT11 是否为 3.3V/5V 供电并共地。
- DATA 是否有上拉电阻，部分模块板载上拉，裸传感器需要外接。
- 是否上电后等待了至少 2 秒再读取。
- 串口请求帧 checksum 是否为 `0x41`。
